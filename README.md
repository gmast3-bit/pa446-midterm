# pa446-midterm

PA 446 - midterm exam. This repository contains a small civic data project in R studio. 

`docs/index.Rmd` : the R Markdown file with all the codes, outputs, and written answers (web scrapping, 
Census data for West Town/Chicago community area 24, and Ohio). 
`docs/index.html` : the knitted page, published with Github pages from the `docs` folder.
The Census API key isn't stored in this repository, it's only installed locally.
